## O3 — Négation talmudique

| Ce que Rétrospective N'EST PAS | Document correct |
|---|---|
| Sprint Review (inspection du produit) | Sprint Review (R4a) |
| Session de thérapie d'équipe | Coaching / facilitation externe |
| Réunion de plaintes sans action | Retro sans ≥ 1 action = inutile |
| Présence des stakeholders | Scrum Team seulement — safe space |
| Réunion mensuelle (si sprint = 2 sem) | Retro après CHAQUE sprint |

## O4 — Format canonique (5 phases Derby & Larsen)

1. **Set the stage : créer un espace safe** → Check-in question + accord de confidentialité
2. **Gather data : faits du sprint (objectif)** → Timeline · données vélocité · incidents
3. **Generate insights : pourquoi ces données ?** → Root cause · patterns · "5 Whys"
4. **Decide : quelle(s) action(s) concrète(s) ?** → ≥ 1 action nommée + responsable + date
5. **Close : ancrer et remercier** → +/delta · appreciation round

---

## Format canonique

| Phase | Durée | Garde-fou |
|---|---|---|
| **Set the stage** | 10 min | Skip = discussions bloquées si tensions |
| **Gather data** | 30 min | Données non-partagées = discussions subjectives |
| **Generate insights** | 40 min | Sauter insights = actions sans cause réelle |
| **Decide** | 30 min | 0 action = retro sans valeur · > 3 actions = surcharge |
| **Close** | 10 min | Skip = équipe repart sans clôture émotionnelle |
