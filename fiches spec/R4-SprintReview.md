```
SprintReview : Ω_incrément → Ω_backlog_révisé
```

| | Contenu |
|---|---|
| **Domaine** | Incrément Done livré à la fin du sprint |
| **Codomaine** | Product Backlog adapté aux nouvelles informations (marché, feedback, changement de contexte) |

## O3 — Négation talmudique

| Ce que Sprint Review N'EST PAS | Document correct |
|---|---|
| Démo formelle sans feedback | La Review = conversation, pas show |
| Rétrospective (amélioration du process) | Rétrospective (R4b) |
| Validation par le management | La validation = Incrément Done selon DoD |
| Réunion de statut sur l'avancement | Daily Scrum (R3c) |
| Occasion de changer le scope du sprint passé | Le sprint est terminé — on adapte le suivant |

---

## O4 — Format canonique

1. **Qu'est-ce qui a été livré ce sprint (selon le DoD) ?** → Présenter l'Incrément
2. **Qu'est-ce qui a changé dans le contexte marché/business depuis le dernier sprint ?** → Inspection contexte
3. **Quelles reactions des stakeholders révèlent de nouvelles informations ?** → Feedback collecté
4. **Comment le Product Backlog doit-il évoluer en conséquence ?** → PB update

---

## Format canonique

| Phase | Participants | Timebox | Output |
|---|---|---|---|
| **Présentation Incrément** | Scrum Team | 30-60 min | Incrément présenté de façon narrative (valeur) |
| **Discussion contexte** | Scrum Team + Stakeholders | 60-90 min | Nouvelles informations marché + feedback |
| **PB update** | PO (+ Dev si besoin) | 30 min | Product Backlog révisé |

| Critère | Règle | Garde-fou |
|---|---|---|
| **Incrément Done** | Seul le Done est présenté | Work-in-progress présenté = mensonge sur le Done |
| **Feedback** | Les reactions stakeholders sont capturées | Review sans feedback = boucle coupée |
| **PB update** | Obligatoire avant la fin de la Review | PB non-mis-à-jour = signal perdu |

## Ker / Im

| | Contenu |
|---|---|
| **Ker** | Incrément présenté · Feedback collecté · Contexte marché mis à jour |
| **Im → Prochain sprint** | Product Backlog révisé · Nouvelles priorités · Hypothèses à tester |
