## O2 — GAFAM best practices

| Pratique | Source | Apport |
|---|---|---|
| OKRs fondateurs | Andy Grove / Intel (1970s) | Objective inspirant + Key Results chiffrés — origine |
| "Measure What Matters" | John Doerr / Google | Diffusion mainstream — CFR (Conversations, Feedback, Recognition) |
| OKRs bidirectionnels | Google | 40% bottom-up + 60% top-down — engagement sans micro-management |
| Stretch goals | Google | Key Results à 70% = succès — 100% = trop facile |
| Weekly check-in | Weekdone / Gtmhub | Progression hebdo — évite l'oubli des OKRs en milieu de trimestre |

## O3 — Négation talmudique

| Ce que OKRs NE SONT PAS | Document correct |
|---|---|
| Liste de tâches ou to-dos | Sprint Backlog (SRD) |
| KPIs opérationnels permanents | Dashboard / métriques produit |
| Évaluation de performance individuelle | RH / 1-on-1 |
| Roadmap produit | BRD Release Roadmap |
| Guaranteed deliverables — ce sont des buts ambitieux | Commitments (OKRs ≠ projets garantis) |

---

## O4 — Format canonique

1. **Quel résultat qualitatif inspire l'équipe ce trimestre ?** → Objective (1 phrase, pas de chiffre)
2. **Comment mesurerons-nous objectivement l'atteinte ?** → Key Result 1 (chiffré, binaire ou ratio)
3. **Quel autre signal confirme l'atteinte ?** → Key Result 2
4. **Quel signal de santé contre-équilibre ?** → Key Result 3 (évite l'optimisation d'un seul axe)

---

## Format canonique

| Élément | Structure | Garde-fou |
|---|---|---|
| **Objective** | "Devenir la référence X pour Y" | Chiffre dans l'Objective = KPI, pas un Objective |
| **Key Result** | "Atteindre X de Y à Z d'ici [date]" | KR non-mesurable = Objective déguisé |
| **Scoring** | 0.0 → 1.0 · 0.7 = succès · 1.0 = trop facile | Score sans baseline = non-évaluable |
| **Cadence** | Trimestre standard · Annuel pour strategy | OKRs mensuels = charge sans valeur |
